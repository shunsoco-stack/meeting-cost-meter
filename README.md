# 会議コストメーター

## 概要

「その会議、いくらかかる？」を見える化する、ブラウザだけで動くデモアプリです。人数と時給から会議のコストをリアルタイムで計測します。デモ用の架空データです。

## 主な機能

### リアルタイムの費用メーター

人数×平均時給、または役職ごとの人数×時給で計算。会議室・ツール代も加算できます。途中参加・退出、時給変更、一時停止・再開、全画面表示に対応しています。ページを閉じても、開始時刻から経過時間を復元します。費用の節目には17種類の例えから金額に合うものをランダムに表示します。

### 終了時の「この会議の値段」と共有

日時・時間・最大同時参加人数・合計・1分あたりの金額をカードに表示。URL、PNG画像、文面で共有できます。対応端末では Web Share API を利用できます。共有用会議名の初期値は「会議」で、元の会議名や役職明細を自動転記しません。個人名を含めないでください。

### 過去の会議

会議名検索、今月の合計、全履歴の平均時間、最高額の会議を表示。検索結果をBOM付きCSVに書き出せます。JSONバックアップの書き出し・検証・復元と、既定データへのリセットも利用できます。

## 計算方法

`時間単価 = Σ（人数 × 時給）+ 会議室・ツール代`

人数や時給を変更するたびに時刻と新しい時間単価を記録し、各区間の実働ミリ秒 × 時間単価 ÷ 3,600,000 を合算します。一時停止中は人件費とツール代を両方停止。1円未満は区間ごとには丸めず、合計の表示時に切り捨てます。結果カードの人数は最大同時参加人数で、1分あたりの金額は合計金額÷実働分数です。0秒の会議は0円/分と表示します。

## 日時の扱い

日付は `YYYY-MM-DD`、時刻は `HH:MM` の日本時間です。開始・終了・人数変更・一時停止区間はepochミリ秒で保存。経過時間は端末の現在時刻との差分で求めるため、日付またぎ・スリープ・再読み込みに対応します。端末時計を変更すると計算に影響します。

初回の履歴30件は、開いた日の日本時間を基準に、過去約2か月の営業日を中心に生成します。すべて現在より前に終了し、0時台でも当日の会議はありません。朝会は月曜、月末レビューは前月末に寄せています。会議名の抽選は重複なしで、開始時刻・長さ・人数は循環配列ではなく疑似乱数でばらつきを持たせています。

## 既存作品との違い

| 作品                             | 主な対象                 | 会議コストメーターとの違い                                           |
| -------------------------------- | ------------------------ | -------------------------------------------------------------------- |
| AI議事録作成アプリ               | 会議の発言と記録         | 本作は音声・議事録・要約を扱わず、人数・単価・時間だけを扱います     |
| AI会議フォローアップエージェント | 会議後のタスクと実行支援 | 本作はフォローアップや外部連携を行わず、コストへの気づきを提供します |

会議室予約、カレンダー連携、勤怠・給与計算も対象外です。

## データの保存先

ブラウザのlocalStorage、キー `mcm:v1` に保存します。マウント後に読み込み、バージョン・型・数値範囲・時系列・ID重複を検証。破損時は架空データに戻して通知します。保存容量や権限の問題も通知します。複数タブ間では保存イベントで同期しますが、同時編集では最後の保存が優先されます。

外部APIやサーバー保存はありません。共有URLにはカードの値をクエリとして含めるため、リンクを持つ人に内容が伝わり、ブラウザ履歴や配信サーバーのアクセスログに残る可能性があります。JSONバックアップには元の会議名も含まれます。

本番のみService Workerを登録し、訪問済みの同一オリジンのページ・静的資産をキャッシュします。共有クエリとRSC応答はキャッシュしません。オフラインでは訪問済みのページを利用できます。

## 技術スタック

Next.js 16 / App Router、React 19、TypeScript、Tailwind CSS 4、CSS、ESLint、Prettier 3。外部Webフォントは使用しません。追加npmパッケージなし。純粋関数のテストは Node.js の標準テストランナーで実行し、既存のTypeScriptでテスト対象をメモリ内変換します。

## ローカル起動方法

Node.js 24以上を使用し、すべてこの `meeting-cost-meter` ディレクトリで実行してください。

```powershell
npm install
npm run dev
```

品質チェックと本番起動:

```powershell
npx --yes prettier@3 --write "src/**/*.{ts,tsx,css}" "tests/**/*.js" README.md
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

`http://localhost:3000` を開きます。本番で未知のIDの `/result/[id]` を開いても、ブラウザの履歴から読み込みます。

静的書き出しは `MCM_STATIC_EXPORT=1` を指定してビルドします。未知のIDを事前列挙できないため、静的ホストでは `/result/*` を共通シェル `/result/view.html` にHTTP 200で割り当ててください。Nginxの設定例は `static-host.conf` にあります。結果はURLのIDからクライアントで読み込むため、シードにないIDにも対応します。ホストの404ページで配信した場合も結果を表示するフォールバックがありますが、HTTP 404になるため共通シェルの割り当てを推奨します。

```powershell
$env:MCM_STATIC_EXPORT="1"
npm run build
Remove-Item Env:MCM_STATIC_EXPORT
node scripts/static-server.mjs
```

静的配信の確認先は `http://localhost:3100` です。設定例には、このNext.js版のページ分割RSCファイル名と出力先の対応も含みます。通常の `npm start` に戻す前には、環境変数を外して `npm run build` してください。

`scripts/browser-check.mjs` は撮影を行わない操作検証スクリプトです。既存のPlaywrightを利用する場合は `MCM_PLAYWRIGHT_PATH` にその `index.mjs` を指定し、3100番ポートで本番サーバーまたは静的配信サーバーを起動して実行します。プロジェクトの依存関係には追加していません。

## デモデータについて

金額は目安、時給・会議は架空です。15〜120分の定例・企画・1on1・振り返り・全社説明会など30件を初回に生成します。全社説明会は参加人数が多く高額で、短い相談や長引いた会議も含まれます。「このデモについて」から既定データに戻せます。
